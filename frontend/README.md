# Frontend

The frontend is a React application built with Vite. For prerequisites, local
setup, environment variables, and Render deployment instructions, see the
[project README](../README.md).

Useful commands from this directory:

```powershell
npm install
npm run dev
npm run lint
npm run build
```

Set `VITE_API_URL` to the backend base URL when it is not
`http://localhost:8080`. Do not include `/api` in the URL.
